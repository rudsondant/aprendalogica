# aprendalogica
Página com os códigos de estudo do livro Aprenda Lógica de Programação com JavaScript e Projetos Web de Rummenigge Dantas.
Para usar os códigos, baixe o arquivo index.html. Abra ele em algum editor de texto. Você irá encontrar a seguinte linha:

>`<script src="script.js"></script>`

Substitua **`script.js`** pelo nome do arquivo que você quer executar. Então se você quer executar **`cap2questao1.js`** subsititua **`script.js`** nesta linha por **`cap2questao1.js`** .
Depois procure o arquivo index.html no seu computador e clique duas vezes nele. O arquivo será executado pelo neu navegador padrão.
